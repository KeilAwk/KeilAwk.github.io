天翼一号2021刷机

（这台应该是天翼一号全系支持比较友好的一台机子吧）

[!tip]

文中指向酷安的链接为防止其他麻烦，不展示直链，仅提供文章或动态id

有需要请自行在手机端酷安搜索天翼一号2021+空格+对应关键词

杂项

若USB连接时断时续，在控制面板的电源计划任务高级选项配置有关USB节能选项、任务管理器内USB Hub与主控的节能属性也一并操作即可

多次尝试失败请重启或换一台电脑、数据线

如果未安装fastboot驱动，可以在晨钟酱官网找到fb驱动，在fastboot下刷机而不是解bl时在设备管理器手动为未知设备选择即可

建议提前了解adb、fastboot命令与cmd使用

解BL

参考Bilibili专栏原文

检查驱动，然后手机进入下载模式，安装驱动，运行命令

设备管理器出现新设备及电脑播放提示音时即可停止长按按键

Zadig工具安装驱动时设备名为iWHALE ****

ID ****则为文中的八位字符

运行解bl的bat脚本时务必等待手机自动重启或cmd窗口焦点回归用户

出现按任意键继续不代表已经完成解bl操作

CHECK_BAUD FAIL 意为设备连接失败，请检查usb连接与驱动

开机时左上角有两行黑底白字警告证明已成功解bl

刷入Flyme

参考Bilibili专栏原文

（原文中system.img映像的su文件未删除，介意的可以在原作者的动态里找到已删除的另一个包）

adb重启进入fastboot模式，运行命令刷入img映像

应该使用adb reboot fastboot而不是adb reboot fastbootd

如果处在蓝底带logo的不完全fastboot模式，需在cmd再次fastboot reboot fastboot

例如，命令fastboot flash system system.img意为向手机的system分区刷入当前电脑目录下的system.img映像

主观感受，也许是flyme系统的特性，感觉系统有点简陋

（有些地方的震动反馈竟然不能关）

刚开始用着有一点点卡，后来慢慢好像就好了

疑似系统的手机管家无法使用

除此之外的系统包

原版精简：酷安 58449748

原版（全量）：酷安 41924738

AOSP 10：酷安 42583099（当然这个里边大佬的群还有其他包，需要自求）

删su文件后修复

删掉flyme系统自带的su文件后重启手机，自动引导到带开机画面的fastboot模式（手机左上角黑底白字写着fastboot）

这个fastboot模式不完整，fastboot reboot fastboot重启到完整fastboot（黑底，可用音量键选择操作）

重新刷入system分区即可（不丢数据）

引导修复

删了或升级了magisk，开机时左上角仅显示一行黑底白字，无法进入系统

这是magisk或用户在操作boot分区之后无法自行签名导致手机bootloader不认并取消启动系统导致

boot引导修复包：酷安 49323193

下载原文评论区文件，重安装提供的驱动，在线刷工具选择.pac线刷包并点击开始，手机进入下载模式并连接电脑，等待工具自动响应并跑完进度条显示Sucess（不丢数据）

上面的原版精简包的评论区也有直接引导fastboot工具

所以更新magisk时请选择手动安装导出boot.img并在电脑签名后再在fastboot模式下自行刷入

修改boot分区时也一样

签名工具：酷安 48980436
